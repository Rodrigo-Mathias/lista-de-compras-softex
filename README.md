# lista-de-compras-softex
Aplicação simples de Lista de Compras desenvolvida com: HTML, CSS, Tailwind CSS e JavaScript. O projeto permite: Cadastrar Produtos, e adicionar a lista de compras. Exibir tabela mostrando os dados de cadastro, sendo possível editar ou excluir itens individualmente. Foram utilizados o HTML com Tailwind, e manipulação do DOM com JS.
